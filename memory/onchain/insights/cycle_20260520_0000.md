## Step 4 — formalize expectancy/Kelly gate

`expectancy.js` and `wf_lpq.js`: compute expectancy and Kelly fraction per hypothesis, with proper walk-forward 60/20/20.

**Definition (proposed, replacing strict +150% gate):**

For a candidate filter F producing trade-fraction returns r_i:
- **Expectancy** E[r] = (1/n) Σ r_i. Promote only if E[r] > 0 on TEST.
- **Kelly fraction** f* = argmax_f (1/n) Σ ln(1 + f·r_i), constrained to [0, 1]. Promote only if f* > 0.05 on TEST (i.e., at least 5% bankroll allocation is geometrically optimal).
- **Geometric per-trade return** g* = exp((1/n) Σ ln(1 + f*·r_i)) - 1. Promote only if g* > 1%/trade on TEST.
- **Minimum n**: TEST n ≥ 20 (relaxed from strict-gate n≥50 since data is sparse).

Applied retroactively to known surviving edges with 60/20/20 walk-forward:

| filter | TRAIN E[r] / Kelly / geom | VAL E[r] | TEST E[r] / Kelly / geom |
|---|---|---|---|
| baseline | -36% / 0 / 0 | -61% | -75% / 0 / 0 |
| H_LP_HIST | -3% / 0 / 0 | -50% | -67% / 0 / 0 |
| H_LP_HIST+QUIET | **+65% / 0.33 / +5.5%** | -32% | -50% / 0 / 0 |
| H_LP_HIST+DISTRIB | +138% / 0.26 / +9.3% | -44% | n=0 |
| H_LP_HIST+QUIET+DISTRIB | +238% / 0.76 / +33% | -22% | n=0 |

**H_LP_HIST+QUIET on TRAIN looked spectacular** (Kelly 0.33, geom return +5.5%/trade — would imply 1.055^100 = ~190× compounded over 100 trades). **On TEST, Kelly drops to 0 and E[r]=-50%.** The fat-tail signature that drove TRAIN (big=5.9%, huge=2.9%) is COMPLETELY absent on TEST and VAL.

Re-tested excluding last 12h carnage (70/30 normal-regime split): same result — TRAIN70 Kelly=0.31 geom=+4.85%, TEST30 E=-29% Kelly=0. The edge is not just "killed by last 12h carnage"; it died around May 18 evening with the fat-tail.

**Verdict**: expectancy/Kelly gate is the **correct** formulation (matches strict-gate's reject on the same evidence), AND it would have approved the May-11-to-May-18 window had we deployed mid-TRAIN. But on validated walk-forward it rejects, same as +150% gate. **No promotion possible this cycle under any gate.**

What changes with the expectancy gate vs strict gate:
- Strict gate (n≥50, avg≥+150%, WR≥60%, rug≤25%) requires fat-tail AND high WR — almost impossible to satisfy on memecoin data without exit-logic that captures the fat tail.
- Expectancy/Kelly gate accepts asymmetric distributions (rare 10×+ winners + many small losses) as long as ln-utility maximization yields positive bankroll growth. **More appropriate for the +1M% goal**, because that goal explicitly relies on fat-tail compounding.
- Both gates reject LP_HIST+QUIET right now (TEST E[r]<0). Good — gate's rejection is correct in current regime.
