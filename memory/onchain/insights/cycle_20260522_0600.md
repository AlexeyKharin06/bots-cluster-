**NEW (7th) — Percentile-redraw boundary drift**:

When 60/20/20 splits are redrawn on a percentile basis every cycle, the TEST window shifts forward each cycle as new data arrives. Tokens that were in TEST one cycle move to VAL next cycle. This makes "TEST passes 3 cycles in a row" meaningless — the TEST sample is partially different each cycle.

**Example this cycle**: c0000 declared TEST = "05-21T14:46+" (n=15 bc=20 BSC). With +98 new trades (+6 BSC bc=20), c0600 percentile-redraw would have TEST = "05-21T19:58+" (n=11 bc=20). MEMEWC+PEDUCK (the 2 bigs that made c0000 TEST K=0.16) silently moved to VAL. New TEST K=0.

**Resolution (rule for brain going forward)**:
- When declaring TEST boundary for a hypothesis: pin it as ABSOLUTE TIMESTAMP in the backlog entry.
- On future cycles: APPEND new data to the same TEST window (don't redraw percentile splits).
- TRAIN/VAL boundaries stay fixed forever; TEST window EXTENDS forward as data accumulates.
- Cross-cycle persistence check then becomes valid: "did TEST stats hold or degrade as TEST n grew from 15 to 21?"

**Applied retroactively**: H_BSC_BC_FULL_B under fixed-boundary TEST grew n=15→21, K dropped 0.16→0.10, geom dropped +2.68%→+1.00%. Signal **degraded** but still passes gate. Honest cross-cycle persistence reading.
