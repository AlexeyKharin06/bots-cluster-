## Step 0a — ROOT-CAUSE BUG LOCATED — concrete patch site

**File**: `/srv/bots/onchain/code/scripts/wallet_v2/serial_sniper.js`
**Lines 85-95** — `getHeliusKey()`:

```javascript
function getHeliusKey() {
  heliusTotalCredits++;
  for (let i = 0; i < HELIUS_KEYS.length; i++) {
    const key = HELIUS_KEYS[heliusKeyIdx++ % HELIUS_KEYS.length];
    if (!_heliusDeadKeys.has(key)) return key;
  }
  // All dead — reset and return first
  _heliusDeadKeys.clear();         // <<< BUG #1: instant reset, no cooldown
  return HELIUS_KEYS[0];
}
```

**Line 341** — `heliusRPC()`:

```javascript
if (parsed?.error?.message?.includes('max usage') || parsed?.error?.code === -32429 || res.statusCode === 429) {
  markHeliusKeyDead(key);
  resolve(heliusRPC(method, params));  // <<< BUG #2: instant recursive retry, no backoff
}
```

**The infinite-loop mechanism** (proven by log signature):
1. Concurrent `heliusRPC` calls hit 429 on different keys → all marked dead in ~1 second.
2. Next call enters `getHeliusKey()`, finds all dead, clears `_heliusDeadKeys` Set, returns key 0.
3. Key 0 still over quota → returns 429 → recursive `heliusRPC` → marks key 0 dead.
4. Loop through all 13 keys in <1s, all return 429, all marked dead, set cleared, REPEAT.
5. At full CPU spin → ~6.8M log entries in 28h.

**Patch proposal** (DO NOT deploy without user approval; this is just a concrete fix for user review):

```javascript
let _allKeysDeadUntil = 0;
function getHeliusKey() {
  heliusTotalCredits++;
  if (Date.now() < _allKeysDeadUntil) return null;  // cooldown active
  for (let i = 0; i < HELIUS_KEYS.length; i++) {
    const key = HELIUS_KEYS[heliusKeyIdx++ % HELIUS_KEYS.length];
    if (!_heliusDeadKeys.has(key)) return key;
  }
  // All dead — engage cooldown 60s rather than instant reset
  _allKeysDeadUntil = Date.now() + 60_000;
  _heliusDeadKeys.clear();
  log('[HELIUS] All 13 keys exhausted — sleeping 60s before retry');
  return null;
}

// In heliusRPC: when getHeliusKey returns null → resolve(null) immediately and let caller handle (do not recurse).
```

This breaks the infinite loop AND signals upstream callers that Helius is overcapped so they can backoff naturally.

**Alternative root fix**: refresh Helius keys (paid quota purchase) — user-side decision.
