## Method (leakage-free)
- Universe = all 250,634 (sym, hour) cells with computable div.
- label_H(cell) = 1 iff a shortening on the SAME sym occurs in **(t, t+H]** (strictly forward; event
  ts floored to the hour to align). Per-sym `np.searchsorted` for the next event after t.
- Baseline P = mean(label_H) over all cells. Conditional P = mean(label_H | div ≥ threshold).
  Lift = conditional/baseline.
- Absolute thresholds = global div p90/p95/p99. Relative thresholds = div / per-sym trailing-30-bucket
  rolling median (causal, min 8 obs) ≥ {3,5,10}×.
- Walk-forward = temporal split at ts_bucket q70 (TRAIN first 70% / TEST last 30%); threshold also
  chosen on TRAIN-only and applied to TEST for an honest OOS read.
- Event-study = for each event, div at offsets {−24,−12,−6,−3,−1,0,+1,+3,+6}h, normalized by that
  sym's own median div (so we measure a SPIKE relative to that coin's normal divergence, not the
  coin's absolute level).
- Concentration = re-run lift after deleting the 8 chronic-divergent coins entirely.

which matters: it means even AFTER removing each coin's chronic divergence level, a SPIKE still

### Concentration (div≥p95, H=6h)
220 true hits across **48 unique syms** (top5 RIVER/ZKP/ENJ/ORCA/LA = 36.8% of hits — not pathological).
EXCLUDING 8 chronic coins: base 0.0735%, div≥p95 P=1.236% → **lift 16.82×** on 9,713 cells, 40 syms
still contributing. (Lift went UP vs the all-coin 14.38× because chronic coins carry high div

### Event-study (THE key finding — div LEADS the event)
offset_h : median(div / sym_median) : n
  −24 : 0.55× : 21      (below the coin's own normal)
  −12 : 1.58× : 26
   −6 : 5.23× : 30
   −3 : 13.66× : 41
   −1 : 28.43× : 174    (peak)
   +0 : 22.59× : 161
   +1 : 16.19× : 159
   +3 : 21.39× : 174
   +6 : 9.92× : 162
Divergence is BELOW normal a day out, rises monotonically from −12h, accelerates into −3/−1h, peaks
just before the change, then DECAYS afterward. This is a genuine leading + mean-reverting structure.
Mechanism (plausible, causal): extreme one-venue funding crowding (cross-ex spread blows out) is the
PRESSURE that makes that exchange shorten its funding interval to control runaway funding; the
divergence is cause, the shortening is response. After the shortening, funding normalizes → div decays.
NOTE on the −1h n-jump (41→174): data density rises near the event (more multi-ex coverage), so I do
NOT over-weight the exact −1h peak; the robust claim is the clean monotone rise −24→−3h on
near-independent samples (n=21/26/30/41). The PRE-event rise is BEFORE any interval changes, so it is
NOT the hourly forward-fill artifact (which can only inflate div AT/AFTER the change).

## Verdict & classification
**C2 = VALIDATED predictive/leading signal** (lift 14–53×, leads by 6–12h, walk-forward stable,
generalizes beyond chronic coins, robust to within-coin normalization). It is **NOT yet an
independent capture edge** — like C8/H38 the *monetization* is still a basis-hedge on the same
funding mechanism, so it does not by itself satisfy KPI-4's "independent edge" bar. Its value is one
of two forms, BOTH requiring a PnL backtest before any paper-stream:
1. **Leading TRIGGER for H31/H34**: anticipate the shortening 3–6h early → pre-position the
   basis-hedge / build a watchlist. CAVEAT: earlier entry is not obviously better for *funding*
   capture (the value of a shortening is the post-event higher-frequency funding; pre-window you
   collect the OLD interval's funding and carry basis risk longer). So this is mainly a
   capital-readiness / watchlist narrower, not a free PnL uplift.
2. **Divergence mean-reversion capture**: div spikes ~28× above the coin's normal then decays to ~10×
   within 6h → the cross-ex funding SPREAD is at an extreme and reverts. Short the spread (long the
   low-funding venue, short the high-funding venue), collect as it normalizes. This overlaps with the
   0500 "Screen B funding-divergence capture" idea AND mechanically with H38's cross-ex-perp variant
   — so it is likely NOT orthogonal, but could be a cleaner *trigger* (spike+revert) than raw magnitude.

**This is why a PnL backtest is the gate**: lift ≠ tradeable edge (Methodology lesson #8/#15 — see H37).
Even at 53× lift the precision is only 6.46%, so a blind per-spike entry would be 93% false-positive;
the realistic use is watchlist/pre-position, whose PnL value must be measured against just waiting for
the reactive H31 trigger.
