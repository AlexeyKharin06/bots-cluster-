## Scope choice

Full universe = 1063 p99 dedup'd triggers across 122 distinct syms × 6
exchanges as primary_ex (gate 372 / bybit 266 / binance 227 / okx 122 /
bitget 75 / hyperliquid 1). Each primary_ex's basis-hedge route requires
spot+perp klines from THAT exchange. Tested first on **binance-primary
subset (227 events / 21%)** because:
- Binance has the highest-data-quality public kline API (perp via fapi, spot
  via api)
- Binance spot universe (~430 USDT bases) covers 18/39 of binance-primary
  syms — gives n=126 events that are end-to-end executable on Binance alone
- Cleanest cross-validation for the cycle 2300 stress estimate (which used
  Bybit borrow as a proxy for basis cost)

Other primary_ex subsets (gate 372, bybit 266, okx 122) deferred to next cycle
— same script, swap API base URL. Expected to broaden universe ~5×.

## Method

`/srv/bots/funding-rate/code/scripts/c2_basis_drift_real.py`:
1. Replicated c2_pnl_uncond.py trigger generation (div ≥ 0.0028, dedup 24h,
   primary_ex = argmin funding, shortening exit logic)
2. Filtered to primary_ex=binance AND sym in binance-spot universe
3. For each trigger (sym, t0, exit_ts): fetched 1h klines for [t0-2h, exit+2h]
   from both fapi (perp) and api (spot)
4. Entry price = open of t0-aligned candle (would be live entry on hourly
   bucket close); exit price = close of last candle ≤ exit_ts
5. PnL_real = fund_collected + (perp_ret − spot_ret) − 40bp round-trip cost
   (5bp slip × 4 + 5bp fee × 4 across both legs)
6. Permutation null: 60 random sym-internal 24h windows (same sym pool, same
   API, same RTC) — n=56 with real klines
