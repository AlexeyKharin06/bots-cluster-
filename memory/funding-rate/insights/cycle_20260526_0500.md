> - Behavioral / ex-specific triggers (e.g. H31 interval-shortening anchored to a single exchange): divergence = outlier-noise marker → **NEGATIVE filter** (higher divergence = lower PnL).

### Mechanism

H38's universe is the chronic-discount cluster (top syms: RIVER, PIPPIN, ENSO, ORCA, RAVE, DRIFT) where ALL exchanges have synchronized strong-negative funding. In this regime:

- LONG primary perp: collects |rate| per period (large positive)
- SHORT hedge perp on different ex (binance or bybit): pays |hedge_rate| per period (large negative drag because hedge ex is ALSO chronic-discount)
- Net = primary_collect − hedge_pay ≈ 0 (when funding rates align across ex)

The hedge perp swallows the primary's funding because both exchanges are taking from the same direction (longs collecting from shorts). The trade only has meaningful PnL when the cross-ex funding GAP is large (which is exactly what c2_div_100bp measures → +0.44pp lift on filter, modest but explainable).

Contrast with H34 (H31's perp-perp hedge): H31's behavioral trigger SELECTS for events with single-ex spike + cross-ex gap → at trigger moment, primary funding is far from hedge funding → SHORT hedge accrues meaningful relative carry. H38's magnitude trigger DOES NOT select for cross-ex dispersion; it selects for absolute magnitude, which on chronic-discount cluster means synchronized funding across ex → no relative carry to capture.
