## Root-cause analysis: empty funding feed

### Hypothesis 1 (initial): keyword regex too strict
The route regex is:
```python
'funding-rate': [r'\bfunding\b.{0,5}\brate\b', r'\bperp\b', r'\bperpetual\b',
                 r'\boi\b', r'\bopen interest\b', r'\bbasis\b'],
```
Russian channels say "ставка фандинга" or "фандинг", neither of which match.
`\bfunding\b.{0,5}\brate\b` even fails on English "funding rates are" because of plural-s placement.

### Fix-2 (autonomous — no user dependency): direct exchange-API funding feed
Funding-rate is one of the cleanest API endpoints in crypto:
- Binance: `GET /fapi/v1/fundingRate?symbol=...` — last 1000 historical
- Bybit: `GET /v5/market/funding/history`
- OKX: `GET /api/v5/public/funding-rate-history`
- Hyperliquid: `info` endpoint with `type=fundingHistory`

A 30-line poller could produce a synthetic `feed_funding.jsonl` populated with structured signals
(symbol, ex, ts, predicted_rate, actual_rate, interval_change_detected). This is BETTER than TG
content for arb because:
1. Deterministic — no NLP, no Telegram desync.
2. Captures interval changes (1h ↔ 8h) which is the H5 announcement-watcher signal directly,
   without the announcement.
3. Cross-exchange spread can be computed in real time.

**Why NOT implement this cycle:** I don't have user confirmation that adding a new poller is
desired (it would run alongside paper bots and add load), and the previous bot graveyard suggests
the user has been burned by naive funding-harvest (R6: −$304/315). I'll propose it as H29 and
let the user decide.

### Fix-3 (cheap, low risk): keyword normalize for whatever data DOES arrive
Even if Fix-1 lands, the regex needs broadening. Recommended:
```python
'funding-rate': [
    r'\bfunding(?:s|\s*rate|\s*rates)?\b',     # funding, fundings, funding rate, funding rates
    r'фандинг',                                  # russian root — covers фандинг, фандинга, фандинговая
    r'\bperp(?:s|etual|etuals)?\b',
    r'\b(?:open\s*)?interest\b',
    r'\bbasis\b',
    r'\bпремия\b',                               # premium
    r'\bставк[аи]\s*фанд',                       # ставка фандинга
]
```
