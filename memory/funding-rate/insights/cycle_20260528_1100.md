## Mechanism

The filter components map directly onto the **(basis ← magnitude/breadth | perp-perp ← dispersion)** duality formalized in Meth #23v2 / #24:
- **rank==1** = primary exchange is the funding OUTLIER → cross-ex DISPERSION exists → perp-perp hedge (LONG low-rate-perp + SHORT high-rate-perp) captures a WIDE spread → works.
- **n_neg_50≥3** = many exchanges deeply negative = SYNCHRONIZED systemic deep-discount → cross-ex funding spread COLLAPSES → perp-perp swallows the trade (exactly the cycle-0526 R23 mechanism where H38 perp-perp standalone was destroyed 97% by chronic-discount synchronization). But basis EXTERNALIZES funding, so deeper/broader negative funding = bigger basis payoff → n_neg_50 helps basis.
